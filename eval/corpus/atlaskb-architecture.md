# AtlasKB Architecture

## Retrieval

AtlasKB uses pgvector for dense vector retrieval and Postgres full-text search
for sparse retrieval. The two result sets are fused with Reciprocal Rank Fusion
(RRF) to produce the final ranking.

## Generation

Answers are generated by an agent that plans retrieval, checks whether the
retrieved context is sufficient, and only then writes a grounded answer with
citations.
